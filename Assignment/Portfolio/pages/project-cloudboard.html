Overview

CloudBoard is a real-time collaborative whiteboard platform designed for teams that think visually. It enables multiple users to draw, sketch, and brainstorm together in real-time with zero latency.

The platform supports vector-based drawing, shape recognition powered by AI, and seamless collaboration across devices. It's built for design sprints, brainstorming sessions, and visual collaboration.

Challenge

Real-time collaboration is inherently complex. The core challenges were:

  • Achieving sub-50ms latency for multi-user canvas synchronization without sacrificing drawing quality
  • Implementing conflict resolution for concurrent edits on the same canvas area
  • Maintaining 60fps rendering performance with hundreds of canvas elements
  • Building an AI shape recognition system that works in real-time

Solution

I designed a custom WebSocket protocol optimized for canvas operations. Instead of syncing pixel data, I sync vector commands — dramatically reducing bandwidth while maintaining precision.

The conflict resolution uses a last-writer-wins strategy with operational transformation for overlapping edits. The AI shape recognition runs inference on the client side using a lightweight TensorFlow.js model, eliminating server round-trips.

Outcome

CloudBoard handles 500+ concurrent users per canvas with an average latency of 38ms. The AI shape recognition achieves 94% accuracy on standard geometric shapes. The platform has been adopted by multiple design teams for their sprint workflows.
