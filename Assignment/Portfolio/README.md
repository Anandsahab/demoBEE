# Chaitanya Anand — Portfolio

A premium, editorial-style portfolio showcasing full-stack projects, engineering thinking, and professional work across finance, healthcare, education, and community.

## Features

- Premium editorial dark UI with gold accents
- Fully responsive (desktop, tablet, mobile)
- Pure HTML + CSS — zero JavaScript
- Engineering notebook aesthetic
- Dedicated project case study pages
- Two resume profiles (Software Engineer + Freelancer)
- Contact page as "Engineering Notebook Final Chapter"

## Tech Stack

- HTML5
- CSS3 (custom properties, flexbox, grid)
- Google Fonts (Space Grotesk + Inter)

## Pages

| Page | Description |
|------|-------------|
| [Home](index.html) | Hero, journey timeline, engineering toolkit, mindset, roadmap |
| [About](pages/about.html) | Engineering notebook hero, debugging philosophy, freelancing |
| [Projects](pages/projects.html) | Project archive with tiered cards |
| [Resume](pages/resume.html) | Career archive with dual profile cards |
| [Contact](pages/contact.html) | Mission control, contact cards, CTA |

## Featured Projects

- **TradeX** — Real-time trading platform (React, Node.js, WebSocket, MongoDB)
- **Orenburg Healthcare** — Product packaging & brand identity
- **Townhall** — Community-driven discussion platform (React, Flask, PostgreSQL)
- **Student Procrastination System** — Analytics-driven study pattern tracker (Python, TensorFlow)
- **Inclusify** — Accessibility platform (HackMol 6.0)
- **Cuddle Buddy** — Social connection interface (React, Tailwind CSS)

## Installation

```bash
git clone https://github.com/Anandsahab/portfolio.git
cd portfolio
```

Open `index.html` in your browser, or use VS Code Live Server.

## Responsive

| Breakpoint | Layout |
|------------|--------|
| Desktop | 1200px+ — Full editorial grid |
| Tablet | 768px — Adjusted columns, scaled typography |
| Mobile | 480px — Single column, stacked cards |
